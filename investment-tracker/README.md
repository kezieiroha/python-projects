# SIPP / ISA Investment Dashboard

Fibonacci retracement alert levels dashboard for SIPP and ISA holdings.
Generated by `build_alert_levels_v19.py` — produces a timestamped `.xlsx` in the same folder on every run.

---

## One-Time Setup

```bash
cd ~/Documents/My\ Documents/Finance/Investments

# Create and activate a virtual environment (recommended)
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

---

## Running the Script

```bash
cd ~/Documents/My\ Documents/Finance/Investments
source .venv/bin/activate          # activate venv if not already active
python3 build_alert_levels_v19.py
```

A new file named `SIPP_Alert_Levels_v20_DDMMYY-HHMM.xlsx` will appear in the same folder.

---

## What Gets Refreshed Automatically (Every Run)

All data is fetched live from Yahoo Finance via `yfinance`:

| Data | Source | Notes |
|---|---|---|
| Current prices | Yahoo Finance | All 44 tickers |
| D200 SMA | Yahoo Finance | 200-day simple moving average |
| W20 / W50 EMA | Yahoo Finance | Daily resampled to weekly (Fri close) |
| M20 / M50 EMA | Yahoo Finance | 10Y monthly close |
| TTM P/E | Yahoo Finance `.info` | None for loss-makers |
| Forward P/E | Yahoo Finance `.info` | None if no estimates |
| D/E ratio | Yahoo Finance `.info` | None for negative-equity companies |
| Net margin | Yahoo Finance `.info` | |
| Analyst consensus | Yahoo Finance `.info` | Strong Buy / Buy / Hold / Sell |
| Analyst price target | Yahoo Finance `.info` | Mean target price |

If `yfinance` cannot reach Yahoo Finance, the script falls back silently to the hardcoded values baked into the script.

---

## Disabling Live Refresh

To run without internet (e.g. offline, or to speed up a test run), set this flag near the top of the script:

```python
LIVE_REFRESH = False
```

The spreadsheet will be built entirely from the hardcoded fallback values.
