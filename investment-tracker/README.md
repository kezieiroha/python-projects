# SIPP / ISA Investment Dashboard

Fibonacci retracement alert levels dashboard for SIPP and ISA holdings.
Generated by `build_alert_levels.py` — produces a timestamped `.xlsx` in the same folder on every run.

---

## One-Time Setup

```bash
cd investment-tracker

# Create and activate a virtual environment (recommended)
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install --upgrade pip
pip install -r requirements.txt
```

---

## Running the Script

```bash
cd investment-tracker
source .venv/bin/activate          # activate venv if not already active
python3 build_alert_levels.py
```

A new file named `SIPP_Alert_Levels_v21_DDMMYY-HHMM.xlsx` will appear in the same folder.

### Optional CLI flags

```bash
python3 build_alert_levels.py --exclude NKE INTC
python3 build_alert_levels.py --add SPCX
python3 build_alert_levels.py --remove SpaceX
python3 build_alert_levels.py --remove SPCX
python3 build_alert_levels.py --offline --output /tmp/workbook.xlsx --run-date 2026-07-28T09:30
```

`--exclude` omits tickers from that run only.

`--add` fetches the ticker live, appends it to the workbook, and persists the generated row in `workbook/data/portfolio_rows.json`. Future normal runs of `python3 build_alert_levels.py` reload and refresh rows marked with `source: "added"` automatically.

`--remove` persistently removes matching rows from `workbook/data/portfolio_rows.json`. Use asset name for shared tickers such as `SpaceX`, because `TBC` is also used by other pre-IPO rows.

`--offline`, `--output`, `--run-date`, and `--data-dir` are primarily for deterministic test runs and controlled workbook generation.

## What Gets Refreshed Automatically (Every Run)

All data is fetched live from Yahoo Finance via `yfinance`:

| Data | Source | Notes |
|---|---|---|
| Current prices | Yahoo Finance | Configured tickers in `workbook/data/market_sources.json` |
| D200 SMA | Yahoo Finance | 200-day simple moving average |
| W20 / W50 EMA | Yahoo Finance | Daily resampled to weekly (Fri close) |
| M20 / M50 EMA | Yahoo Finance | 10Y monthly close |
| TTM P/E | Yahoo Finance `.info` | None for loss-makers |
| Forward P/E | Yahoo Finance `.info` | None if no estimates |
| D/E ratio | Yahoo Finance `.info` | None for negative-equity companies |
| Net margin | Yahoo Finance `.info` | |
| Analyst consensus | Yahoo Finance `.info` | Strong Buy / Buy / Hold / Sell |
| Analyst price target | Yahoo Finance `.info` | Mean target price |

If `yfinance` cannot reach Yahoo Finance, the script falls back to the static values in `workbook/data/portfolio_rows.json`.

## Static Data

| Data | How to update |
|---|---|
| 2022 bear market lows | Edit `workbook/data/portfolio_rows.json` |
| Cycle ATHs | Edit `workbook/data/portfolio_rows.json` |
| Thesis / notes | Edit `workbook/data/portfolio_rows.json` |
| Fib Methodology macro swing examples | Edit `workbook/data/macro_swing_data.json` |
| Fallback moving averages | Edit `workbook/data/ma_data.json` |
| Fallback analyst consensus / targets | Edit `workbook/data/analyst_data.json` |
| Provider ticker lists and aliases | Edit `workbook/data/market_sources.json` |
| Adding a new ticker | Run `python3 build_alert_levels.py --add TICKER` |

## Offline Runs

To run without internet, or to produce a deterministic test workbook, use `--offline`:

```bash
python3 build_alert_levels.py --offline
```

The spreadsheet will be built from the static JSON fallback values.

## Project Layout

| Path | Owns |
|---|---|
| `build_alert_levels.py` | Command shim |
| `modules/cli.py` | Argument parsing and run orchestration |
| `modules/config.py` | Paths, run clock, environment settings |
| `modules/models.py` | `PortfolioRow` and the shared typed views |
| `modules/calculations.py` | Fib levels, zone classification, upside, trend labels |
| `modules/data_store.py` | JSON load/save for `workbook/data/` |
| `modules/market_data.py` | Yahoo Finance and Alpha Vantage integration |
| `modules/portfolio.py` | Row assembly, `--add` / `--remove` / `--exclude` |
| `workbook/` | Sheet rendering, one module per sheet |
| `tests/` | Unit tests plus an offline workbook contract test |

Run the tests with `python3 -m pytest`.
